# A30 / s2d — interleaved vision without a resampler

**Status**: design settled 2026-09-05, not yet registered, not yet built.
**Supersedes nothing.** Adds a fourth fusion arm alongside s2a / s2b / s2c.
**Registry row**: not yet written — run `/register-experiment A30` before any launch
(AGENTS.md §4). A30 is free; the registry currently stops at A29.

## 1. Hypothesis

> Removing the `LatentSummarizer` and feeding pixel-shuffled V-JEPA patch tokens
> through an MLP projector at fractional temporal positions recovers the ramp signal
> that s2b's pooled arm destroys.

Measured context lives in [`../ablations.md`](../ablations.md) — do not restate it here.
The two facts the hypothesis rests on:

- s2b's Δ ramp NMAE sits at the seed floor; s2c, the only arm that bypasses the
  summarizer entirely, is the only arm that clears it.
- The latent probe measured ramp R² **0.0060 at 1×1 vs 0.0512 at 4×4** (t+30). The
  spatial structure is present in the V-JEPA latents; pooling destroys it.

Pre-registered floors: ramp NMAE **0.0011**, skill score **0.0037**.

## 2. Why the summarizer is the suspect

`LatentSummarizer` is a Perceiver resampler — one learned query per visual step
cross-attending the whole patch field (`latent_queries`, shape
`[1, n_vis_steps · n_sub, d_model]`). `CrossModalAdapter` sits *downstream* of it, so
widening `n_soft_tokens` (A13) could only fan one pooled vector into N copies. That
null was guaranteed by construction.

Frontier MLLMs abandoned the resampler. NVIDIA, *Nemotron 3 Nano Omni: Efficient and
Open Multimodal Intelligence*, arXiv **2604.24954v2**, 11 May 2026, §2: encoder →
**MLP projector** → decoder, with no learned-query compressor anywhere in the model.
s2d adopts that shape.

## 3. Design

### 3.1 Vision path

| Stage | Detail |
|---|---|
| Cache | `/leonardo_work/IscrC_MTSFM/vjepa_cache/uk_pv/vit_large_f8_s224_nonhrv_sp45` (v2 non-HRV, cache of record — see [`../dataset.md`](../dataset.md)) |
| Input | `video_latents [B, 4, 196, 1024]` — 4 latent frames × 14×14 patches × V-JEPA ViT-L/16 dim |
| Pixel shuffle | r=2, i.e. Nemotron's 4× token reduction: 14×14×1024 → **7×7×4096**, 49 tokens/frame. Space-to-depth, *not* averaging |
| Projector | 2-layer GELU MLP, 4096 → 768 → 768 (~3.7 M params) |
| Embedding | learned **49-entry spatial cell embedding**. No temporal-slice embedding — see §3.3 |
| EVS | post-projector, in `d_model`: per cell (h,w), cosine dissimilarity between consecutive latent frames; frame 0 pinned to max as anchor; keep the globally most-dissimilar **98 of 196** (q=0.5) |

EVS keeps a fixed count, so sequence length is static and batching stays rectangular.

`LatentSummarizer` and `CrossModalAdapter` are absent from this path entirely.

### 3.2 Sequence

**141 tokens** = 42 TS macro patches + 98 visual + 1 future.

Fractional RoPE positions derived from `video_delta_t`. `layers.py:90` already does
`position_ids[:, None, :].float()`, so fractional positions need **no kernel change**.
Tokens surviving EVS carry their `(frame, cell)` identity, so position and cell
embedding follow the token through pruning. The 15 covariate rows pad to 141, as the
existing interleaved path already does.

### 3.3 The 8-hour-patch constraint

uk_pv is **30-minute** data (`configs/data/ukpv.yaml`: 14-day history, `horizon: 12`
= 6 h). `input_patch_size: 16` therefore makes **one TS token = 8 hours**, and
672 / 16 = 42 patches. `visual_window_hours: 6.0` (the W5 recency cap) means all four
V-JEPA latents fall inside the **final TS patch**.

Consequence: genuine *between-token* interleaving is impossible at patch=16. There is
exactly one TS token co-temporal with vision. s2d's interleaving is **sub-patch** —
four latents at distinct fractional positions inside patch 41.

This is not a defect, it sharpens the contrast: s2b places every visual token at one
position; s2d places them at 4 distinct positions × 49 cells. The delta is exactly
*positional and spatial resolution of the visual payload*.

Rejected alternative: re-extracting the cache at `window_h=24` so vision spans three
patches. Costs a fresh extraction against a 1 TB quota that has already overflowed once
(32.84 TB view-save incident), and csi autocorrelation ~0.78 at 45 min means 6–24 h-old
frames carry little.

Because fractional positions already encode time, a learned temporal-slice embedding is
omitted deliberately: it would give the model a second encoding of the same axis and
hand **A09 frame-shuffle an escape hatch** — shuffling permutes positions, but a slice
embedding could re-leak order.

### 3.4 Training

Warm start from the **stage-1 checkpoint** (same as s2c and A29, so the three-way
attribution holds).

**Stage 0** — ~500 steps, projector + cell embedding trainable, everything else frozen.
Adopted from Nemotron §3.1.1 (vision projector warmup); guards against a freshly
initialised projector injecting noise into a frozen Chronos-2 at step 0. Runs inside
the same job, so step budget and seed protocol are unchanged.

Then the s2b/s2c policy verbatim: `freeze_chronos: true`, `freeze_visual_encoder: true`,
`visual_dropout_prob: 0.5`, `numeric_dropout_prob: 0.1`. Mixer `selfattn` — every
number in the registry is selfattn, and no Grassmann result exists anywhere on disk.
`compute_marginal_gain: true`. Seeds 42 / 43 / 44.

### 3.5 Evaluation

- **EVS q-sweep** {0, 0.3, 0.5, 0.7} on the trained checkpoint — free motion-selectivity
  evidence. If ramp NMAE improves as q rises, the useful signal is in the tokens that
  *changed*, i.e. moving cloud edges.
- **A09 frame-shuffle** — falsifiable for the first time on any arm. It is inert on s2b
  (no positional encoding on the KV; `kv_mask = zeros` at `model.py:102`;
  `MHA(config, use_rope=False)` at `layers.py:450`) and inert on the summarizer at
  `n_vis_steps == 1`.
- **A10 swap-plant**, **A10b stale-sky**.
- Scored on the **full test set** — the h≤5 restriction is void, see §5.

## 4. Compute and pack layout

Per-token per-layer cost is ≈ `4d²` + `4d²` + `2·d·d_ff` ≈ 9.44 MMAC; the attention
score term (`2·L·d`) never dominates at these lengths. Cost is therefore ~linear in
token count.

| Arm | seq | vs s2b |
|---|--:|--:|
| s2b today (N=1) | 44 | 1.0× |
| s2d, 49/frame, no EVS | 239 | 5.6× |
| **s2d as specified (EVS q=0.5)** | **141** | **3.3×** |
| full V-JEPA field (rejected) | 827 | ~21× FLOPs, ~19× activations |

No measured wall-clock exists on this box (`logs/slurm/` is empty locally, result JSONs
carry no timing keys), so the above is analytic-relative only.

**Smoke test before committing the pack**: 1 job, 1 GPU, batch 16, ~10 min. If it fits,
`ablation_pack.sbatch` waves are:

- **wave 1** — s2d × 3 seeds + the 7×7 probe (§5)
- **wave 2** — A29 × 3 seeds + A02 seed 42 (closes the n=1 BLOCKING hole on s2b)

If the smoke test OOMs, s2d takes all 4 GPUs via DDP, one seed per pack.

## 5. Open risks and honesty flags

1. **Sub-patch, not MLLM interleaving.** §3.3. The manuscript must not claim the latter.
2. **EVS is trained in here; in Nemotron it is runtime-only** ("a runtime-only feature
   that drops video tokens after the ViT blocks and the vision adapter"). Conv3D is
   their trained mechanism. Deliberate deviation, stated as such.
3. **s2d moves four things at once vs s2b** — summarizer removal, 49-cell resolution,
   fractional positions, EVS. Three are isolable post-hoc: EVS by the q=0 eval,
   positions by A09, resolution by A29 as the pooled control. The summarizer removal
   itself is the residual and is **not** separately isolable.
4. **7×7 is unmeasured by the probe.** `scripts/probes/latent_pooling_bottleneck.py:62`
   hardcodes `GRID = 4` ("finest spatial grid retained; 2x2 and 1x1 nest inside"), and
   the s2c config comment is explicit that 4 was chosen so "a null here is interpretable
   rather than confounded by an unmeasured resolution". Re-running the probe at
   `GRID = 7` is a one-constant change and minutes of GPU; it is in wave 1 for that
   reason. Without it, a 7×7+EVS null has two explanations that cannot be separated.
